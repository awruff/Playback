# Keyframe

Makes first person replays look like what the player saw.

## Building

- `./gradlew :<version>:build` builds one version into `versions/<version>/build/libs/`.
- `./gradlew :<version>:runClient -Pstandalone` runs the client without Flashback, in standalone mode.
